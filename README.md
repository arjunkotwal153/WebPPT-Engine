## ✨ Features

- 🎥 **Cinematic 3D Camera System**: Fluid, continuous panning and zooming across a massive virtual canvas.
- ⚡ **GPU-Accelerated Animations**: Silky smooth 60fps animations for data flowing, attack scenarios, and architecture diagrams.
- 🎮 **Interactive HUD**: Live scene tracking, progress indicators, and instant point-and-click slide navigation.
- 🔒 **Zero-Trust Visualized**: Abstract cybersecurity concepts turned into beautiful, digestible animated pipelines.

## 🚀 Quick Start

To run this presentation locally on your own machine:

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/zero-trust-presentation.git

# 2. Navigate into the directory
cd zero-trust-presentation

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The presentation will be running smoothly at `http://localhost:5173`.

## 🏗️ Architecture

This is **not** a traditional PowerPoint or Keynote converted to HTML. This is a custom-engineered React application:

- **Frontend Framework**: React 18
- **Animation Engine**: GSAP (GreenSock Animation Platform) 
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS with custom design tokens
